# Banking Loan Analytics | Excel, SQL, Tableau & Power BI

## Project Overview

The Banking Loan Analytics project focuses on analyzing banking operations, loan portfolio performance, and credit and debit transactions using Excel, MySQL, Tableau, and Power BI.

The main objective of this project is to transform raw banking data into meaningful business insights through data analysis, SQL queries, KPI calculations, and interactive dashboards.

This project covers three major analytical areas:

### 1. Bank Analytics

- Overall banking performance analysis.
- Branch-wise revenue and collection analysis.
- State-wise banking performance.
- Product and loan-purpose analysis.
- Loan disbursement trends.
- Branch performance comparison.

### 2. Loan Analytics

- Total loan amount and funded amount analysis.
- Total loan count and collections.
- Interest and revenue analysis.
- Loan status analysis (Active, Closed, and Delinquent).
- Default loan count and default rate.
- Delinquent loan count and delinquency rate.
- Age-group-wise loan distribution.
- Verification status analysis.
- Grade-wise loan analysis.
- Branch-wise and state-wise loan performance.

### 3. Debit & Credit Analytics

- Total credit and debit amount analysis.
- Credit-to-debit ratio.
- Net transaction amount.
- Account activity ratio.
- Daily, weekly, and monthly transaction trends.
- Branch-wise transaction performance.
- Bank-wise transaction analysis.
- Transaction method distribution.
- Branch transaction growth analysis.
- High-risk transaction identification.
- Suspicious transaction frequency analysis.

## Tools & Technologies

- **Excel:** Data analysis, KPI calculations, pivot tables, and dashboard development.
- **MySQL:** Database creation, data loading, SQL queries, and data validation.
- **Tableau:** Interactive dashboards and data visualization.
- **Power BI:** Business intelligence reports and interactive dashboards.

## Project Workflow

1. Data Collection – Collect banking, loan, and transaction datasets.
2. Data Preparation – Review and prepare the data using Excel.
3. Database Creation – Create the banking database and tables in MySQL.
4. Data Loading – Import datasets into MySQL.
5. SQL Analysis – Write SQL queries to calculate KPIs and analyze business performance.
6. Dashboard Development – Build interactive dashboards using Excel, Tableau, and Power BI.
7. Data Validation – Compare dashboard results with SQL query outputs.
8. Insights & Recommendations – Identify trends, performance indicators, and potential risk areas.

**Debit & Credit Analytics**

## Project Outcomes

- Developed an understanding of banking and loan portfolio performance.
- Analyzed customer transaction behavior and financial activity.
- Identified default and delinquency indicators in loan data.
- Compared banking performance across branches and banks.
- Analyzed transaction trends and growth patterns.
- Created interactive dashboards for business reporting.

## Conclusion

This project demonstrates how raw banking data can be transformed into meaningful business insights using Excel, MySQL, Tableau, and Power BI.

By combining Bank Analytics, Loan Analytics, and Debit & Credit Analytics, the project provides a comprehensive view of banking performance, loan portfolio health, transaction activities, and risk indicators.

The dashboards and analytical reports support better business understanding and data-driven decision-making.
